# Habit Tracker

Aplicativo mobile desenvolvido em Flutter para gerenciamento de hábitos, permitindo o cadastro, acompanhamento e organização de hábitos bons e ruins de forma simples e intuitiva.

---

## Descrição

Aplicação voltada para o controle de hábitos diários. O usuário pode adicionar novos hábitos, classificá-los como positivos ou negativos e acompanhar sua evolução ao longo do tempo.

---

## Objetivo

Este projeto tem como objetivo aplicar conceitos fundamentais de desenvolvimento mobile, incluindo:

* Gerenciamento de estado com Provider
* Organização modular de código
* Navegação entre telas
* Manipulação dinâmica de dados
* Construção de interfaces responsivas

---

## Funcionalidades

* Cadastro de hábitos
* Edição de hábitos existentes
* Remoção de hábitos
* Classificação entre hábitos bons e ruins
* Contagem de hábitos ativos
* Interface simples e intuitiva
